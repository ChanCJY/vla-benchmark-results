📝 测评说明

    ✍️ 如何更新数据

    所有分数都集中在 data.js 一个文件里，改完刷新即可。

    1

    填分数

    打开 data.js，在 scores 中把 null 替换为测评成功率数字（百分数）。

    2

    加任务

    在 tasks 数组里增加一行即可新增任务；RoboTwin 全部 50 个任务名可参考 RoboTwin/description/task_instruction/。

    3

    加模型

    在 models 数组追加模型，并在各基准的 scores 中补上对应键的分数。

    data.js 编辑示例

    {
  task: "stack_blocks_three",        // 任务名（与目录中的文件名保持一致）
  label: "堆叠三个积木",              // 可选：页面上显示的中文名
  scores: {
    starvla: 76.0,                   // 填写真实成功率，例如 76.0
    xvla: null,                      // null 或留空 = 页面显示 —
    pi05: 80.0
  }
},

    Built with the TermiBrain-style light theme · 分数请以 data.js 为准
